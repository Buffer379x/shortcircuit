# ShortCircuit contributor guidance

- Read the [Claude Code handoff](docs/CLAUDE_CODE_HANDOFF.md), [project status](docs/PROJECT_STATUS.md), and [decisions](docs/DECISIONS.md) before continuing development. Keep project documentation in English.
- Codex built the initial implementation. The handoff gives Claude Code the remaining implementation work, the four-perspective review, and the subsequent improvement work. Develop ShortCircuit independently and document its own behavior and contracts.
- Use functional copy throughout the UI, including sign-in. Maintain English and German UI strings centrally in `frontend/src/i18n/`.
- The admin interface follows Polar Signal: the [design system](docs/DESIGN_SYSTEM.md), [UI guidelines](docs/UI_GUIDELINES.md), and [branding](docs/BRANDING.md) are binding. Before building UI, check `frontend/src/lib/` and `frontend/src/styles/ui.css` for an existing component and reuse it. Do not define new buttons, colors, font sizes, radii, spacing, or component styles in a page. Add a shared component only for an uncovered functional need, and document it. Keep one primary action per view, use pink only for actions, selection, focus, and the primary data series, and avoid static `style` attributes (the admin CSP blocks them). `npm run check` must pass, including the design lint, contrast, and catalog checks.
- Run one modular Rust process in one unprivileged Docker container. Keep the public and admin listeners separate and SQLite on persistent local storage. Activate outgoing integrations explicitly.
- Recreate previous short URLs manually when needed. Verify the public host, exact slug, and expected redirect before updating production routing.
- Keep visit limits transactional. Bound analytics and background work separately. Give security, data integrity, and reliability priority over performance improvements.
- Keep changes and commits focused. Version the schema and API. Run the relevant [tests](docs/TESTING.md) and report actual results. Use synthetic local test data and keep credentials, tokens, and personal data out of source, logs, and artifacts.
- Update the [threat model](docs/THREAT_MODEL.md) and [security guide](docs/SECURITY.md) when trust boundaries change. Add regression coverage for changes to host routing, auth, outgoing requests, restore, and import.
- Develop source in the public GitHub repository. Release artifacts, paid resources, license changes, and production infrastructure changes each require explicit approval.
