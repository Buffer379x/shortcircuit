# Reporting Security Issues

ShortCircuit 0.1 is in development. A release image is pending. Until a private reporting channel is available, report security issues to the project maintainer through an existing private contact. Omit tokens, full destination URLs, and personal visitor data.

The first release will list the approved private reporting channel and supported versions here. See the [threat model](docs/THREAT_MODEL.md) and [security design](docs/SECURITY.md) for the planned controls and trust boundaries.
