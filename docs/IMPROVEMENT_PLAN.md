# Improvement plan

This plan turns the [quality review](QUALITY_REVIEW.md) into ordered tasks. P0 and P1 come first. Each task names its findings, files, dependencies, and an observable acceptance check. Tasks that touch data, public behavior, or deployment also state their risk and how to roll them back. The Result column records what was implemented and verified. Release actions, template and image tag changes, and changes to the owner's infrastructure stay outside this plan and need the owner's approval.
